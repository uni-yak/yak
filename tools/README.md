# tools

## 职责

开发辅助与生成工具集合。`oracle/` 是信任链外只读参考；`symgen/lex_tables.py` 及其配置源参与前端静态表生成，属于参考前端的信任链。

## 结构

- `env.sh` —— 环境自检：对账 `../versions.lock`，检查换行、大小写冲突、路径合规
- `diff.sh` —— 三级 diff：MIR / YSM / 目标代码的前后比对
- `oracle/` —— 差分对拍参考：只读引用外部旧仓库，不复制任何内容
- `tree-sitter/` —— 编辑器语法高亮（`.yak` / `.ysm`）
- `symgen/` —— 读取 `../spec/lang/symbol.def`，生成固有静态符号表
- `audit_spec.py` —— 检查规格状态、依赖、错误码和拒绝规则映射，输出结构审计及未冻结债务

## 边界

- 与构建脚本的区别：本目录工具可缺失，构建脚本是必需品。
- 禁止把 platform 或 release 判定逻辑放这里。

## 约定

- 普通辅助工具的临时输出放 `../tmp/`；显式生成命令可更新已登记的静态表，`--check` 模式只读比较。
- 工具失败必须明确退出码，禁止半量成功后继续。
