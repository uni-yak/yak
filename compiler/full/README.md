# compiler/full

## 职责

完整编译器 `yakc-full`：在固定点门禁保护下由 `min` 生长而来，支持完整语言与优化管线。

> T2 固定点之前本目录不投入实现，`min` 是唯一工作编译器。

## 能力范围（链接式，不复制清单）

- 支持的语言：基座 + 已实现的脱糖规则，`../../spec/lang/sugar.md`
- 支持状态矩阵：`../../spec/index.md`
- 优化管线：`../../spec/target/optimize.md`

## 结构

- `src/` —— 源码（组件同构于 `../min/src`，另含 `opt/`）
- `build.sh` / `verify.sh` / `STAGE` —— 三件套

## 边界

- 与 `../min/` 共存期间，二者必须通过差分门禁保持一致语义。
- 优化遍不得改变语义等价性，判定见 `../../spec/proc/gate.md`。

## 约定

- 不以"重写"方式推进，而是逐特性迁移 + 差分对拍。
- 资源预算（输入、步数、内存、递归深度）写入门禁，防止出现不可控膨胀。
