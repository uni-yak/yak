# compiler/full

## 职责

在已归档的 T2 基座上开发 T3 编译器。当前入口只构建首批待确认候选，不是正式交付的 `yakc-full`，不启用优化管线。

能力边界以 [能力矩阵](../../spec/index.md) 和 [语法基座](../../spec/lang/base.md) 为准；候选隔离与确认条件见 [规格状态规约](../../spec/proc/status.md)。

## 结构

- [源码](src/README.md)：候选前端、降级和两个入口，复用 `../min/` 中的基座管线。
- [build.sh](build.sh)：构建一个显式候选入口；[selfhost.sh](selfhost.sh)：用同一原生 min 编译器和扫描器构建两个入口。
- [STAGE](STAGE)：记录候选阶段和基座。

## 构建与边界

日常验证使用 [独立候选门禁](../../test/full/README.md)。它在专用 `tmp/full-stage-*` 内构建并保留回执，不占用 `min` 的共享构建暂存区。直接调用构建入口只用于独占工作树：显式指定目标、配对原生工具，以及互不重叠的 `tmp/` 子目录作为输出和审计目录。

候选不使用 Seed、不进入 min 默认产物或发布包；候选通过不等于规格确认或正式登记。
