# compiler

## 职责

编译器实现体集合。契约一律在 `../spec/`，本目录只放实现。

## 结构

- `min/` —— 最小编译器 `yakc-min`：用基座语法编写，点火期由 `yak-seed` 解释执行
- `full/` —— 完整编译器 `yakc-full`：固定点达成后由 `min` 在门禁保护下生长

## 边界

- 与 `../spec/lang/base.md`：`min` 的源码必须落在基座范围内。
- 与 `../spec/index.md`：各编译器支持的数据类型与语法特性，以该矩阵为唯一真源，各编译器目录只链接不复制。
- 与 `../seed/`：`seed` 在开始阶段执行 `min`，两者生命周期不同。

## 约定

- 不新增第三套并行实现，避免双实现漂移。
- 每个编译器目录自持 `build.sh` / `verify.sh` / `STAGE` 三件套。
