# spec/ir

## 职责

规定编译中间表示：编译器的语言无关、平台无关的内部形态，也是审计与差分比对的对象。

## 结构

- `mir.md` —— MIR：SSA 中端形态、指令集与容量约束
- `ysm.md` —— YSM：发射前审计镜像，确定性序列化格式，逐字节可 diff

## 边界

- 与 `../lang/`：`lang` 是源语言语义，`ir` 是 lowering 之后的形态。
- 与 `../target/`：目标层消费内存 MIR 产出机器相关产物；`.ysm` 仅为可选审计镜像，不进入发射。

## 约定

- 中间表示必须先于实现确定，所有转换对脱糖前后的语义等价负责。
- YSM 为发射前唯一审计对象：任何产物的可追溯性以 YSM 为准。
