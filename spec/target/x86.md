# x86

## 元信息

- 名称：x86（x86_64 指令子集与编码契约）
- 级别：base
- 状态：草案
- 依赖：`emitter.md`、`../lang/layout.md`、`register.md`、`select.md`

## 一、范围

1.1 本文规定 x86_64 目标的允许指令子集、寄存器集合与编码确定性契约。

1.2 base 期 `yakc-min` 发射器为栈槽模型（无寄存器分配，`register.md` 推迟 full）；指令子集限于栈槽直译所需的最小集。

1.3 编码必须确定：同一 MIR opcode + 操作数产生唯一字节序列；禁止依赖汇编器的启发式选择（如多余前缀、等价编码歧义）。

## 二、寄存器集合

| 类别 | 寄存器 | 用途 |
|:---|:---|:---|
| 通用 | `rax rcx rdx r8 r9 r10 r11` | 调用方保存（Windows 与 Linux 共用） |
| 通用 | `rdi rsi` | 依目标 ABI 划分：Windows x64 为被调方保存（`abi-win.md` 三）；Linux System V 为调用方保存（`abi-linux.md` 三） |
| 通用 | `rbx r12 r13 r14 r15 rbp` | 被调方保存（Windows 与 Linux 共用） |
| 栈 | `rsp` | 栈指针 |
| 指令指针 | `rip` | 控制流 |

base 期栈槽模型：局部变量占固定栈槽 `[rbp-N]`；热寄存器只放返回值（`rax`）与当前表达式中间值。

## 三、允许指令子集

| 类别 | 指令 |
|:---|:---|
| 数据移动 | `mov`、`movzx`、`movsx`、`lea`、`push`、`pop` |
| 算术 | `add`、`sub`、`imul`、`mul`、`idiv`、`div`、`neg`、`inc`、`dec`、`cqo`/`cdq` |
| 位运算 | `and`、`or`、`xor`、`not`、`shl`、`shr`、`sar` |
| 比较 | `cmp`、`test` |
| 控制流 | `jmp`、`call`、`ret` |
| 条件跳转（有符号） | `je` `jne` `jl` `jle` `jg` `jge` |
| 条件跳转（无符号） | `jb` `jbe` `ja` `jae` |
| 溢出检测 | `jo` `jno`（有符号）、`jc`/`jb`（无符号进位/借位） |
| 栈帧 | `enter`/`leave` 或 `push rbp; mov rbp,rsp; ...; pop rbp` |
| 陷阱 | `int3`（`trap`，`mir.md` 0xC3） |
| 空操作 | `nop` |

禁止使用：SIMD、AVX、BMI、ADX、浮点（base 无浮点）、`cpuid`、内联汇编伪指令。

3.1 **跳转选择与 MIR 语义的对应**（发射必须遵守）：

| MIR 形态 | x86 序列 | 说明 |
|:---|:---|:---|
| 比较 `eq` / `ne` | `cmp` + `je` / `jne` | 与符号性无关 |
| 比较 `lt` / `le` / `gt` / `ge`（**有符号**操作数） | `cmp` + `jl` / `jle` / `jg` / `jge` | 有符号条件 |
| 比较 `lt` / `le` / `gt` / `ge`（**无符号**操作数） | `cmp` + `jb` / `jbe` / `ja` / `jae` | 无符号条件；不得复用有符号跳转 |
| 算术 `add` / `sub` / `mul` / `neg`（**溢出 → trap**） | 有符号：算术指令 + `jo` → `trap_target`；无符号：`add`/`sub`/`mul` + `jc`/`jb`（或 `jo` 对 `mul`）→ `trap_target` | 依操作数符号性检查 `OF` 或 `CF` 转移清理块 |
| 回绕 `wrap_add` / `wrap_sub` / `wrap_mul` | 算术指令（**忽略 `OF`/`CF`**） | 不发射溢出跳转；标志位不得影响控制流 |
| 除法 `div` / `rem`（除零 → trap） | `cmp` 除数为 0 + `je` → `trap_target`；有符号用 `cqo`/`cdq` + `idiv`（含 `MIN/-1` 检查），无符号清高位后用 `div` | 有符号 `MIN/-1` 商溢出跳 `trap_target`，取余为 0 |
| 移位 `shl` / `shr`（移位量 ≥ 宽度 → trap） | `cmp` 移位量 + `jae` → `trap_target`，再移位 | 无符号比较 |

3.2 有符号与无符号跳转不得混用：操作数类型的符号性由 `TypeSig` 决定，发射器必须按该类型选择对应条件跳转。混用会改变比较语义，为发射错误（EM-5）。

## 四、编码确定性

4.1 每条指令的编码由 opcode + 操作数类型唯一决定；等价编码选最短形式（如 64 位寄存器清零选 2 字节 `xor eax,eax`，而非带冗余 `REX.W` 的 `xor rax,rax` 或 `mov rax,0`）。

4.2 禁止多余前缀（如冗余 `REX`）；前缀只在操作数宽度或寄存器要求时发出。

4.3 立即数编码按目标类型宽度：`u8/i8` → 8 位、`u16/i16` → 16 位、`u32/i32` → 32 位、`u64/i64` → 64 位（`mov r64, imm64` 用 `REX.W + mov`）。

4.4 跳转目标编码为相对偏移；偏移宽度选最短（`jcc rel8` 优先，超出用 `jcc rel32`）。

## 五、栈帧

5.1 函数入口：`push rbp; mov rbp, rsp; sub rsp, <frame_size>`；`frame_size` 为 16 字节对齐后的局部总大小。

5.2 Windows x64 须预留 32 字节 shadow space（`abi-win.md`）。

5.3 出口：`add rsp, <frame_size>; pop rbp; ret`（或 `leave; ret`）。

## 拒绝形态

| 编号 | 条件 | ErrorCode |
|:---|:---|:---|
| X-1 | 使用允许子集外指令 | E7101 |
| X-2 | 编码歧义（同一 opcode + 操作数产生多字节序列） | E7102 |
| X-3 | 多余前缀或非最短编码 | E7103 |
