# emitter

## 元信息

- 名称：emitter（目标发射与链接绑定）
- 级别：base
- 状态：草案
- 依赖：`../ir/mir.md`、`../ir/ysm.md`、`../lang/symbol.md`、`abi-win.md`、`abi-linux.md`、`pe.md`、`elf.md`

## 一、范围

1.1 发射器消费已检查的内存 MIR、目标 profile 与链接输入，生成目标对象和最终链接产物。`.ysm` 是可选审计镜像，不是发射输入；审计/固定点门禁启用时由 `../proc/fixpoint.md` 比对。

1.2 发射器不得重新解释 Yak 源语言类型语义、所有权、布局或名字解析；对象布局与 `.iface` profile 校验以 `../lang/layout.md`、`../lang/symbol.md` 为准。

## 二、输入与绑定

2.1 每个目标对象只接受一个已登记的目标 profile；MIR、`.iface`、ABI 与对象格式 profile 不一致时拒绝。

2.2 发射前，所有跨模块引用必须已由 `(DependencyId, ExportId)` 解析为唯一 `LinkId`；固有符号不得生成外部 `LinkId`。

2.3 链接输入按 `(LinkId, 定义单元摘要)` 的稳定字节序处理；禁止依赖宿主链接器的哈希遍历、绝对路径或输入发现顺序。

2.4 重定位仅可引用已定义的 `LinkId`、本对象局部标签或目标格式允许的静态节；重定位宽度、加数与地址范围必须满足当前目标格式。

2.5 目标对象格式必须是当前 profile 显式登记的 PE/COFF 或 ELF 变体；未知格式、未知重定位或未知节属性不得降级处理。

2.6 `enum_dispatch` 按 tag 索引跳转表发射：tag 为该 enum 声明顺序确定的连续整数（`../lang/type/enum.md` 定义、不可由源码读写或伪造），臂表按 `VariantId` 升序（`../ir/mir.md` 5.3）。发射器以 tag 作表索引直接取得目标 `BlockId`，不发射运行期标签选择或线性比较链。tag 越界只能源于 MIR 穷尽性失败，须在检查期由 M-5 拒绝；发射期若观察到越界 tag 则不变量失败，不生成跳转。跳转表的节布局、重定位与地址计算必须满足确定性与当前目标格式，不得引入宿主地址或遍历顺序依赖。

## 三、输出

3.1 成功时写出确定性的对象文件或最终可执行文件；失败时不得安装部分产物。

3.2 发布产物不包含 `.sym`、`.iface` 或编译期 enum 成员表。调试信息的目标表示另行登记，不得改变语言对象布局。

## 四、拒绝形态

| 编号 | 条件 |
|:---|:---|
| EM-1 | 引用的 `LinkId` 没有唯一已定义目标 |
| EM-2 | 同一 `LinkId` 存在多个定义 |
| EM-3 | 重定位目标、宽度、加数或地址范围不合法 |
| EM-4 | 当前 target profile 不支持请求的对象格式、节属性或重定位种类 |
| EM-5 | 条件跳转与操作数符号性不匹配（有符号 / 无符号混用），或 `wrap_*` 回绕运算发射了溢出跳转 |
| EM-6 | 当前 profile 的 ABI 不支持的按值形态：切片按值返回 |

EM-6 的拒绝时机为发射期，错误码 `E8023`。依据 `abi-win.md` 2.2 / `abi-linux.md` 2.2（切片参数展开为指针与长度）与 `abi-win.md` 2.8 / `abi-linux.md` 2.9（切片按值返回未登记形态），切片按值返回必须拒绝，不得隐式降级为单指针或截断搬运。聚合按值传参与返回的形态分别由 `abi-win.md` 2.7–2.8 与 `abi-linux.md` 2.8–2.9 登记，不属于 EM-6；实现因外部边界或资源上限无法安全发射时，仍须以 EM-6 失败关闭，并在实现文档登记具体边界。
