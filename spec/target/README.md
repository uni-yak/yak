# spec/target

## 职责

规定目标平台与后端事实：指令、调用约定、对象格式、发射器契约、优化与代码生成。与语言无关、与编译器阶段无关。

## 结构

平台与格式：

- `x86.md` —— 允许的指令子集与编码契约
- `abi-win.md` —— x86_64 Windows 调用约定（首发目标）
- `abi-linux.md` —— x86_64 System V 调用约定
- `pe.md` —— PE/COFF 对象格式
- `elf.md` —— ELF 对象格式

后端与代码生成：

- `emitter.md` —— 发射器契约：输入 MIR + 目标描述 → 目标代码
- `optimize.md` —— 优化管线（AOT，逐遍可关断）
- `register.md` —— 寄存器分配
- `select.md` —— 指令选择

## 边界

- 与 `../lang/`：本目录不重定义任何语言语义。
- 与 `../ir/`：本目录消费内存 MIR，不定义 MIR；`.ysm` 仅供审计比对，不进发射。
- 与 `../proc/`：本目录规定"产出什么格式"，流程层规定"如何构建与验证"。

## 约定

- 每个目标平台的事实在此成文，禁止在实现代码里以注释形式规定平台事实。
- 新增平台需新增一组 `abi-*` / 格式文档，并登记入 `../index.md` 矩阵。
