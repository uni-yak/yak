# optimize

## 元信息

- 名称：optimize（AOT 优化管线）
- 级别：full
- 状态：草案
- 依赖：`../ir/mir.md`、`../lang/owner.md`、`../lang/unsafe.md`、`../lang/asm.md`、`../lang/atomic.md`、`../proc/fixpoint.md`、`emitter.md`

## 一、范围

1.1 本文规定 full 层 AOT 的 MIR → MIR 优化管线、优化档位、逐遍开关、语义保全不变量与确定性约束（`../ir/mir.md` 1.4）。

1.2 base 期 `yakc-min` 不实现优化遍，始终运行最短管线（`Y0`）；优化只在 full 层激活。

## 二、优化档位与遍闭集

| 档位 | 定位 | 包含的优化遍（按固定执行顺序） |
|:---|:---|:---|
| `Y0`（默认） | 最短管线、零优化 | 无（原样传递已验证 MIR） |
| `Y1` | 确定性安全优化 | 常量折叠 → 拷贝传播 → 死代码消除（DCE）→ 基本块合并与不可达裁剪 |
| `Y2` | 确定性激进优化 | `Y1` 全部遍 → 确定性内联（遵循 `@inline` 与固定成本阈值）→ 公共子表达式消除（CSE）→ 循环不变量外提（LICM）→ 支配树冗余越界/溢出检查消除 |

2.1 **逐遍可关断**：每个优化遍具备固定唯一名称，支持命令行独立启用或关断，用于缺陷定位与固定点审计。

2.2 **MIR 合法性闭环**：任一优化遍的输入与输出均须通过 `../ir/mir.md` 验证（SSA 支配关系、所有权三态、`out` 槽位状态机、穷尽分派与位置专属清理边；违反为 OPT-1）。

## 三、语义保全不变量

3.1 **可观察行为不变**：优化不得改变程序的正常输出、退出码、错误载体 `T!E` 传播结果、作用域逆序析构顺序或 `out` 槽位提交/回滚状态。

3.2 **陷阱精确性**：溢出、除零、移位越界、索引/切片越界与 `assert` 的陷阱检查仅在编译期可数学证明永不触发时才可消除；不得把可能陷阱的指令提前移过可观察副作用或消除私有清理边（OPT-2）。

3.3 **底层内存屏障不可跨越**：`@volatile_load` / `@volatile_store`、`@atomic_*`、`@fence` 与未标注可消除的 `@asm` 均为优化硬屏障；不得消除、合并或跨越其内存序/易失边界重排访存指令（OPT-2）。

3.4 **效果契约保持**：优化不得引入新的堆分配，不得使原 `no_alloc=true` 或 `no_trap=true` 的函数退化为 false。

## 四、确定性

4.1 优化决策（含内联成本、遍历顺序与迭代上限）只允许依赖 `DefId`、`LocalId`、`BlockId` 与指令序号的固定顺序。

4.2 禁止依据运行时间、宿主机 CPU 核数、内存地址或无序哈希表决定是否执行变换；同一源码、同一依赖 `.iface` 与同一优化档位/开关必须产出逐字节一致的 MIR 与目标代码（OPT-3）。

## 五、拒绝形态

| 编号 | 条件 |
|:---|:---|
| OPT-1 | 优化遍产出违反 `../ir/mir.md` 合法性不变量的 MIR |
| OPT-2 | 优化非法消除、合并或重排 `@volatile_*`、原子操作、`@fence`、`@asm` 或可观察陷阱/析构路径 |
| OPT-3 | 同一输入与优化配置产出非确定性 MIR 或目标代码 |
| OPT-4 | 指定未知优化档位、未知遍名称或非法遍执行顺序 |
