# select

## 元信息

- 名称：select（指令选择）
- 级别：full
- 状态：草案
- 依赖：`x86.md`、`register.md`、`emitter.md`、`optimize.md`、`../ir/mir.md`、`../lang/atomic.md`、`../lang/asm.md`

## 一、范围

1.1 本文规定 full 层将已验证 MIR 指令及 full 保留号段（`../ir/mir.md` 4.15）映射为目标机器指令序列的确定性选择契约。

1.2 base 期 `yakc-min` 采用固定一对一栈槽直译模板（`x86.md` 三）；本规格在 full 层统一规范标量、浮点、底层内存、原子、位操作内建、SIMD 与内联汇编的指令选择。

## 二、覆盖域与目标特性门控

2.1 **base 核心域**：完整覆盖 `../ir/mir.md` `0x01`–`0xD2`（整数 checked 与回绕算术、位运算、有/无符号比较、转换、内存访存、聚合构造、所有权与切片、调用、分派、`out` 槽位与终结指令）。

2.2 **full 扩展域**（位于 `../ir/mir.md` `0xE0`–`0xFF` 保留号段）：
- **IEEE 754 浮点**（`f32`/`f64`）：在 x86_64 上选择标量 SSE2 指令（`movss`/`movsd`、`addss`/`addsd`、`ucomiss`/`ucomisd` 等），遵守确定性舍入与 NaN 比较语义；
- **底层内存原语**：`@volatile_*` 与 `@unaligned_*` 选择单条精确宽度访存指令且禁止拆解/消除；`@bitcast` 仅执行零成本寄存器重解释或等宽位搬运；
- **硬件原子与屏障**（`../lang/atomic.md`）：在 x86_64 上按内存序选择 `mov`（自然对齐原子读写）、`xchg`、`lock cmpxchg`、`lock xadd`/位逻辑 RMW、`mfence` 与自旋等待提示 `pause`；
- **底层算术与位内建**：饱和算术、带进位/溢出标志算术，以及字节序翻转（`bswap`）、循环移位（`rol`/`ror`）、前导/尾随零与位计数（按目标特性门控选择硬件指令或确定性软件回退）；
- **便携 SIMD 向量**：按目标特性集（如 SSE2 / AVX2 / NEON）选择定宽向量指令；
- **内联汇编**：按 `../lang/asm.md` 模板与约束展开。

2.3 **特性白名单门控**：任何基线以外的 CPU 扩展指令（如 AVX、BMI、POPCNT、ADX）仅在目标 profile 显式启用对应特性位时才允许选择；未启用时须选择基线回退序列或按 SL-1 拒绝。

## 三、语义精确性与编码确定性

3.1 **符号性严格隔离**：沿用 `x86.md` 3.2，有符号与无符号操作数的比较跳转、除法（`idiv` vs `div`）、右移（`sar` vs `shr`）与宽化（`movsx` vs `movzx`）严格按 `TypeSig` 区分，禁止混用（SL-2）。

3.2 **陷阱检查不可省略**：所有未由 `optimize.md` 数学证明消除的溢出、除零、`MIN/-1`、移位越界与数组/切片越界检查必须生成对应跳转至该指令的私有清理块或 `trap_target`（SL-3）。

3.3 **唯一确定性选择**：对同一目标 profile、同一特性集、同一 MIR 形态与操作数类型，指令选择器必须输出唯一固定的指令序列，遵守 `x86.md` 第四节（最短等价编码、禁止冗余前缀；SL-4）。

## 四、拒绝形态

| 编号 | 条件 |
|:---|:---|
| SL-1 | 遇到当前目标 profile 或特性集不支持的 MIR opcode、类型宽度或扩展指令 |
| SL-2 | 混用有符号与无符号比较、移位、除法或扩展指令 |
| SL-3 | 省略必要的运行期陷阱检查或破坏位置专属陷阱清理边 |
| SL-4 | 同一 MIR 形态产生非确定性指令序列或非法操作数编码 |
