# host（种子宿主服务）

## 元信息

- 名称：host（种子宿主服务）
- 级别：点火宿主
- 状态：确认
- 依赖：`../lang/foreign.md`、`seed.md`、`error.md`

## 状态与边界

状态：草案。用户已选择先扩充受限参数和文件服务，再接入 T1。
本草案明确允许 `yak-seed` 解释执行时的参考实现与相应测试；不因此确认 `yakc-min` / `yakc-full` 的目标代码、布局或 ABI 能力。
本文补充 `../lang/foreign.md` 的种子宿主服务，不开放任意 C 符号、裸指针或文件句柄。
语言程序只接收字节视图、整数和普通完成结果；服务失败统一进入陷阱路径。
本项不改变 `T!E`、视图位置限制、foreign 的拥有型参数限制或目标 ABI。

## 宿主登记

命令行形态为 `yak-seed ENTRY [--module NAME=PATH] [--input NAME=PATH] [--output NAME=PATH] [-- ARGS...]`。
`ENTRY` 为解释执行入口。`--` 之后的参数才进入 Yak 参数列表，不包含解释器、入口和宿主登记选项。
每个登记必须包含非空名称和路径，同类名称不可重复；未知选项、缺失值、重复登记或未登记的模块、输入、输出均拒绝。
名称为 UTF-8 文本，不包含 NUL；文件服务按名称精确查表，不将名称解释为路径，不搜索工作目录或环境目录。
路径仅由启动解释器的宿主提供，Yak 代码不能通过参数内容增加文件权限。

## 参数服务

`foreign args_count(): u32;` 返回参数数量。

`foreign args_len(index: u32): u32;` 返回指定参数的 UTF-8 字节数，不含结尾 NUL。

`foreign args_read(index: u32, buffer: &[u8]:ReadWrite): u32;` 将整个参数复制到 buffer 开头并返回字节数，不追加 NUL。索引越界或 buffer 容量不足均陷阱，不截断。

## 文件服务

`foreign file_size(name: &[u8]): u64;` 返回已登记输入文件的字节数。

`foreign file_read(name: &[u8], offset: u64, buffer: &[u8]:ReadWrite): u32;` 从已登记输入文件的 offset 开始读取，最多写入 buffer 长度个字节，返回实际读取数。到文件末尾返回 0；非法名称、偏移不可表示、定位或读取错误均陷阱。

`foreign file_write(name: &[u8], data: &[u8]): void;` 为已登记输出独占创建新文件并完整写入 data。已有目标、重复写入、打开、写入或关闭失败均陷阱，不覆盖已有文件。

本次解释执行非零退出时删除本次成功创建的输出；正常零退出才提交这些输出。回滚不删除执行前已存在的文件。多输出不是跨进程的原子事务；构建脚本仍须在独立临时目录运行，并在完整门禁通过后安装最终产物。

## 能力与资源

以上服务不创建 Yak 拥有型堆值，可声明 `foreign #name`。写入参数缓冲要求 ReadWrite；只读视图不能升级。参数、名称、文件内容和桥接临时内存均计入种子内存预算。服务不返回宿主句柄，不保存调用方的视图。
标准输入/输出的 `read`、`write`、`exit`、`assert` 保持原有签名和失败语义。

## 模块执行

每条 import 必须命中一个 `--module` 登记；模块名使用完整 `::` 路径精确匹配，不由实际文件路径推导语言身份。
模块源文件只由解释器加载；Yak 的 file_read 权限不因此扩大。
模块图按声明顺序确定性深度优先加载，拒绝循环、自导入和同一物理文件的重复身份。
跨模块访问要求限定路径和 export；私有 function、foreign、const 不跨模块可见。
加载依赖、检查声明和初始化常量必须先于入口调用；非根模块不得定义 main。

## 验收

覆盖参数零项、多项、中文、容量不足和索引越界；输入未登记、只读缓冲、偏移与文件末尾；输出不存在、已有目标、重复写入和多输出失败回滚；模块缺失、循环、私有访问、同名类型身份及跨模块调用。
宿主登记与构建脚本的集成测试不替代 T1 目标产物执行或 T2 固定点门禁。
