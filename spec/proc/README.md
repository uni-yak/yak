# spec/proc

## 职责

规定**流程与门禁**：如何构建、如何验证、如何判定收敛、如何报告诊断。

## 结构

- `build.md` —— 确定性构建规则：遍历序、原子安装、回滚
- `gate.md` —— 门禁定义：快速门禁（开发）与完整门禁（提交）
- `host.md` —— 种子宿主的受限参数、模块与文件服务
- `seed.md` —— 种子点火时序：Seed 点火生成 `yakc-min`，原生固定点验收后进入 `yakc-full` 阶段
- `fixpoint.md` —— 固定点收敛：三遍编译逐字节一致
- `diag.md` —— 诊断协议（JSONL）与输出格式
- `lsp.md` —— 独立语言服务的协议、文档分析和候选交付
- `error.md` —— 错误码编码规则与诊断协议
- `error.def` —— 错误码数据真源：段、码位、关联拒绝编号与描述
- `error_history.json` —— 错误码历史基线：防止已登记码位重编号或静默改义
- `status.md` —— 规格状态规则（确认 / 草案-可实施 / 草案 / 缺失）与冻结、实现门禁
- `shell.md` —— 可移植 shell 白名单：MSYS2 与 Linux 行为一致的操作集

## 边界

- 与 `../target/`：流程层不规定平台事实。
- 构建目录与临时产物的清理规则见 `build.md`，验收记录的归档规则见 `gate.md`。

## 约定

- 任何构建脚本中的非常规判断（原子性、回滚、预算）必须能追溯到本文档层条文。
- 错误码新增只在本目录 `error.def` 登记；编码规则与诊断协议写在 `error.md`。
