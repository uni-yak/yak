# base

## 元信息

- 名称：base（最小语法基座）
- 级别：base
- 状态：草案
- 依赖：`lex.md`、`parse.md`、`owner.md`、`module.md`、`foreign.md`、`type/` 各类型文档

## 一、范围

1.1 base 是语言的**自举源码子集与最小核心基座**：高阶语法分别按 `sugar.md` 的解析后纯语法糖或类型检查后降级规约落到具体 MIR。

1.2 base 一经确认即**冻结其源码语法与既有行为**；full 层演进通过 `sugar.md` 降级与独立 full 内核规格（如浮点、裸指针、`unsafe`、`asm`、并发原子、顶层初始化器、自定义 `Drop`）按预留号段向后兼容扩展，不得破坏或改写已冻结的 base 形态。

1.3 `min` 编译器的源码必须落在 base 范围内，且 `min` 前端与检查器只接受 base 形态（R-24 严格拒绝未启用项）；`full` 编译器在此基座上生长高阶降级与底层内核能力。

## 二、记号约定

2.1 形态编号：`B-1`、`B-2` …；拒绝形态编号：`R-1`、`R-2` …。

2.2 语法描述采用缩进产生式；`[]` 表示可选，`*` 表示零次或多次，`|` 表示择一。

2.3 本文只做规定；语义解释、设计动机一律不写入。

2.4 示例中的参数名、绑定名一律使用 `x`、`name`、`arg` 一类占位记号，不使用与关键字同形的词；默认态必须标注"无修饰符"。

## 三、词法接口

3.1 源码编码 UTF-8，标识符与字面量的字符范围见 `lex.md`。

3.2 保留字（base 生效，任意位置禁止作标识符）：`function` `let` `var` `const` `if` `else` `elseif` `while` `break` `continue` `return` `match` `enum` `struct` `true` `false` `import` `export` `foreign` `out` `as`。

3.3 保留占位字（base 期禁用，出现即拒绝；full 层启用）：`loop` `unsafe` `interface` `impl` `implements` `for` `in` `is` `type` `never` `null`。

3.4 上下文关键字（词法层输出标识符，仅限下列语法位具有关键字语义，其余位置为合法标识符）：

- `Read` `Write` `ReadWrite`：能力后缀位（紧随访问位置的引用类型之后）。

`move` 不是上下文关键字，也不是参数修饰符；它与其他所有权动作名一样为普通标识符，转移动作只写作 `@move(e)`。所有权动作与 `@`-原语统一以 `@name(args)` 调用，无裸形与前缀运算符形（见 3.8、7.11、7.16）。

3.5 不引入 `ref`、`val` 关键字：引用记号固定为 `&`，绑定记号固定为 `let` / `var` / `const`。不引入 `Ok` / `Err` / `Some` / `None` 构造器。

3.6 运算符（base）：`+ - * / %` `== != < <= > >=` `&& || !` `& | ^ << >>` `=` `.` `[]` `::` `:` `?` `as` `..` `@`。full 追加 `?.`、`??`、`..=` 与 `is`。

3.7 字面量：整数、布尔、字符、字符串。禁止浮点字面量。字符串字面量类型为 `&[u8]`（指向静态存储，词法层保证 UTF-8）。`null` 为 full 层可空字面量，base 期禁用。

3.8 token 位置规则：

- `&&` 在前缀位拆分为两个借用记号；二元位为逻辑与。
- `:` 用于类型标注位、返回类型位与能力后缀位；模块路径用 `::`。能力后缀只在访问位置的引用类型归约之后有效。
- `?` 为表达式后缀传播，只作用于 `T!E`；类型尾缀 `T?`、可空访问 `?.` 与回退 `??` 为 full 层形态且只作用于 `T?`。
- `!` 两用：类型位中缀为 `T!E` 载体；表达式位为逻辑非及 `!=` 组合。不存在 `value!` carrier 解包。
- `|` 三用：`T!(E1 | E2)` 括号内为错误集，full 类型位为普通联合，表达式位为按位或。
- `..` 仅用于索引位 `[a..b]`。
- `&` 在函数名位产出函数静态引用（类型 `&function(P): R`），与借用视图的 `&` 同形但语义不同（静态、Copy、无能力、可入聚合）。`function` 为保留字，声明位后随函数名、类型位后随 `(` 由位置区分。
- `@` 为原语前缀记号；原语调用统一形为 `@name '(' args ')'`，如 `@move(e)`、`@copy(e)`、`@clone(e)`、`@drop(e)`、`@push(x, e)`、`@len(s)`、`@wrap_mul(a, b)`、`@assert(cond)`、`@exit(code)`；无前缀运算符形。`@` 不得用于用户标识符；裸 `move` / `copy` / `clone` / `drop` / `push` / `len` / `wrap_add` / `wrap_sub` / `wrap_mul` / `assert` / `exit` 为普通标识符。

## 四、类型

4.1 base 允许的类型集合：

| 编号 | 类型 | 说明 |
|:---|:---|:---|
| T-1 | `u8` `u16` `u32` `u64` `i8` `i16` `i32` `i64` | 定宽整数 |
| T-2 | `bool` | |
| T-3 | `char` | Unicode 标量值 |
| T-4 | `void` | 空返回类型，只允许出现在返回类型位；可作 `T!E` 的 `T` |
| T-5 | `enum` | 和类型，标签为连续小整数，可携带至多一个 payload |
| T-6 | `struct` | 嵌套记录，字段集合固定，字段值可经可写 place 修改 |
| T-7 | `[T; N]` | 定长数组，owning |
| T-8 | `T[]` | 动态数组，owning，头部 `{ptr, len, cap}`，非 `Copy`，编译器生成析构 |
| T-9 | `&T` / `&T:Read` / `&T:ReadWrite` | 引用视图 |
| T-10 | `&[T]` / `&[T]:ReadWrite` | 切片视图，胖指针 `{ptr, len}` |
| T-11 | `T!E` | 可失败返回载体：函数返回、函数静态引用返回与局部 carrier 绑定；完成语义原语 |
| T-12 | `AllocError` | 固有错误 enum，唯一标签为 `OutOfMemory`；`@clone` 与 `@push` 的失败载体 |
| T-13 | `&function(P): R` | 函数静态引用，值类型，Copy，无所有权 / 析构 / 能力 |
| T-14 | `Nullable<T>` | 编译器内部可空 carrier；只由 full 源语法 `T?` 脱糖产生，不是用户路径或 BuiltinId |
| T-15 | `PlainUnion<T...>` | 编译器内部普通联合；只由 full 源语法 `A | B | ...` 脱糖产生，不是用户路径或 BuiltinId |
| T-16 | `Fallible<T, ErrorSet<E...>>` | 编译器内部可错 carrier；只由源语法 `T!E` 生成，不是用户路径或 BuiltinId |

4.2 字符串与字节：base 无 owning 字符串类型。字符串字面量类型为 `&[u8]`；字符处理经 `char` 解码实现。`string` / `&string` 与 UTF-8 边界切片为 full 层登记（包装 `T[]` 实现）。

4.3 固有参数化形式白名单：`[T; N]`、`T[]`、`&T`、`&[T]`、`T!E`、`&function(P): R`、`T!(E1 | E2)`（错误集）、`Nullable<T>`、`PlainUnion<T...>`、`Fallible<T, ErrorSet<E...>>`。后三者只能由语法或 `sugar.md` 生成的无名称内部 AST 节点产生；用户不得书写它们、定义新的参数化类型、泛型函数或关联类型。

4.4 视图类型的书写位置限制：`&T`、`&[T]` 只允许出现在参数访问位与局部绑定类型；不得作为 struct 字段、enum payload、数组元素、泛型实参、函数返回类型。唯一例外是 `const` 初始器中的字符串字面量及其此前 const 引用可定型为静态 `&[u8]` 视图；该视图不得再嵌入聚合或作为返回值。函数静态引用 `&function(P): R` 与 owning 类型 `T[]` 不受此限制，可作字段、enum payload、元素与泛型实参。

4.5 禁止的类型：用户定义泛型、闭包类型、浮点、裸指针、动态派发类型；base 期另禁 owning 字符串、`tuple`、`T?`、普通 `A | B`（推迟登记见 11.2）。

4.6 类型转换：无隐式转换；显式转换只允许类型文档中登记的 `as` 白名单。

4.7 整数字面量定型：由上下文定型；无法唯一定型时必须显式类型标注或后缀。不提供默认整数宽度。

4.8 类型声明：`enum` 与 `struct` 的声明产生式见 `parse.md`。`enum` 标签可携带至多一个 payload；`struct` 字段集合固定（无增删），字段值可经 owning 可写 place 或 `&T:ReadWrite` 修改。

4.9 错误集联合：`E1 | E2 | …` 是由 enum 类型构成的**闭集联合**；表示为静态内联 tagged union，**不分配堆**。成员经展开后不得有可重叠的运行时成员，否则拒绝。联合归一化（去重、顺序）与物理表示见 `type/result.md` 草案与 `layout.md` 草案。`E1 | E2` 只作 `T!E` 的 `E` 位使用。

## 五、声明与函数

5.1 函数声明：`function CallableName(参数): 类型 { 块 }`（`CallableName ::= Ident | HashName`，`parse.md` 三）；返回类型不可省略。

5.2 参数形态（访问标注或按值，唯一表面）：

| 写法 | 能力 / 所有权 | 调用点要求 |
|:---|:---|:---|
| `x: &T`（无能力后缀） | `Read` | 静默（传 place 或值，编译器隐式借用） |
| `x: &T:Read` | `Read`（显式，语义同上） | 静默 |
| `x: &T:ReadWrite` | `ReadWrite` | 静默（传可写 place） |
| `x: &T:Write` | `Write` | 必须写 `out slot` |
| `x: T`（非视图 `T`） | 按值：`T` 为 Copy 时复制；`T` 为非 Copy owning 时转移所有权 | Copy 静默；非 Copy owning 必须写 `@move(e)`（`owner.md` 2.3） |

函数引用参数 `cb: &function(P): R` 按值传递（Copy），不参与能力系统，可作字段与元素。

5.3 不提供 `move x: T`、`var x: T` 与 `out x: T` 参数模式；`move` 只作为 `@move` 原语名出现，`var` 只在绑定位，`out` 只在槽位声明位与调用点。不提供 `x: T:Cap` 参数位糖，`&` 必写。

5.4 绑定：`let` 不可重新赋值，`var` 可重新赋值，`const` 为编译期常量；`let` / `var` / `const` 均必须有初始化器。`const` 初始化器只允许字面量、既有 `const`、enum 标签构造（payload 仍须为常量初始化器）与定长数组字面量的组合。

5.5 输出槽位声明：`out name: T;`。不得带初始化器，只允许函数或块局部位置；`T` 须为 owning 非 carrier 具体类型，不得为视图、函数静态引用、`void`、普通联合、`T?` 或 `T!E`。其状态机见 7.12。

5.6 遮蔽：同一作用域禁止重复声明；嵌套作用域允许遮蔽外层名称。未使用绑定为拒绝形态。

5.7 递归允许；递归深度受实现登记的上限约束。

5.8 失败返回：记号 `T!E`（`E` 必须为单个 enum 或按 4.9 归一化的错误集；`T` 可为 `void` 表示无成功 payload）。`T` 与 `E` 经别名展开后不得有可重叠的运行时成员，否则拒绝。构造采用**上下文注入**：已知目标 `T!E` 时，定型为 `T` 的表达式构造 success，定型为 `E` 的表达式构造 error；`void!E` 的 success 由 `return;` 构造。不引入 `Ok` / `Err` / `Some` / `None` 构造器；`match` 不作用于 `T!E`。

`?` 只作用于 `T!E`，且所在函数必须返回 `U!E_dst`。success 产出 `T`（`void!E` 仅继续）；error 按 `E_src ⊆ E_dst` 规则重封装后提前返回。`T?` 与普通联合上的 `?` 分别按 `option.md` OP-3 与 `union.md` UN-3 拒绝；普通非 carrier 值上的 `?`、返回类型非可错或错误集不为子集按 `result.md` RE-4 拒绝。不得把 error 隐式提升为 runtime 终止。

手动恢复（`.catch` / `.then` / `.or` / `.unwrap`）为 full 层；它们只接受 `T!E`，不得以普通联合或可空载体替代。base 无 `T?` 与普通 `A | B`；缺席模式以自定义 enum 或 `bool` + `out` 表达。

5.9 多值返回：用 `struct` 返回值、`T!E` 或 `out` 槽位表达。

5.10 根模块程序入口为 `function main(): void`，正常完成以退出码 0 结束。`main` 必须显式处理 `T!E`，不能使用传播 error 的后缀 `?`。显式退出调用语言级控制流原语 `@exit(code)`（退出码为 `u8`；原 9.2 的 `foreign exit` 仅作 T1 兼容保留）。构建中的入口选择见 [构建规格](../proc/build.md) 3.1，目标入口与完成状态见 [Win64 ABI](../target/abi-win.md) 和 [Linux ABI](../target/abi-linux.md)。

5.11 无增契约 `#`：`function #名(参数): 类型 { 块 }` 或 `foreign #名(...)` 声明该 callable 及其可达 Yak 调用图不增加 Yak 运行时堆分配。`#` 是声明修饰符（非独立 callable 身份），`#foo` 与 `foo` 不可共存；声明后的调用、取地址和导入只写 `foo`。编译器对全部函数计算 `no_alloc`（`mir.md`），导出结果写入 `.iface`（`symbol.md`）；`#` 声明要求 `no_alloc == true`，否则按 R-29 拒绝。

增（禁止）：`@push`、`@clone`、非空 `T[]` 构造、运行时内部堆分配服务、不可验证的 `&function` 间接调用。减（允许）：无增析构和运行时内部堆释放服务。中性（允许）：`@move`、`@copy`（Copy 类型位拷贝不分配）、`@len`（读胖指针）、`@wrap_add`/`@wrap_sub`/`@wrap_mul`（回绕算术不分配）、`@assert`/`@exit`（控制流原语不分配）、算术/位/比较/控制流/借用/切片/字段/enum/carrier、经 `no_alloc` 验证的 `call_local` / `call_far`。base 生成的析构路径无增；full 自定义 `Drop` 激活后，只有其析构路径同样证明 `no_alloc` 才可视为减。`#` 不进修饰名，不分配 `BuiltinId`。`#` 只用于具名 callable；匿名函数（S-21）仅自动计算 `no_alloc`，被 `#` 直接调用时递归验证。源级 `foreign #` 的核心 I/O 服务为 `read` / `write`（`exit` / `assert` 的 `foreign` 形态仅作 T1 兼容保留）；堆分配 / 堆释放是运行时内部服务，不可由用户声明。

## 六、控制流与求值

6.1 `if` / `elseif` / `else`：条件必须为 `bool`。`elseif` 为单关键字（非 `else if` 两词）。

6.2 `while`：支持带标签 `break` / `continue`。`loop` 为 `while true` 的糖，登记于 `sugar.md`，base 期禁用。标签产生式见 `parse.md`。

6.3 `match`：对 owning enum 值必须穷尽全部标签；允许 `_` 通配臂。`match` 消费 scrutinee：非 `Copy` enum 移动并使源 place 失效，`Copy` enum 先复制且源 place 保持有效。`match` 不作用于 `T!E`、`T?`、ErrorSet 或普通联合。含 payload 的标签可写一个绑定名，绑定时 payload 为 **move**（不可部分移动）；省略绑定名表示在该臂丢弃 active payload。无 payload 标签不得书写 payload 绑定。各臂可按各自标签独立选择是否绑定。base 不提供借用模式或部分解构。

6.4 提前返回：`return`。`if let` 当前未激活；它未来若登记，只能是 `T?` 的内部 carrier dispatch 糖，base 期禁用。

6.5 求值顺序：

- 表达式自左向右求值，顺序确定，不依赖实现选择。
- `&&` / `||` 短路求值：左操作数已能决定结果时不求值右操作数。
- 实参按源码从左到右求值，全部实参的类型、借用、所有权与槽位检查完成后才进入被调方。

6.6 溢出与转换：

- `+ - * / %` 与一元 `-` 的整数溢出、`MIN / -1`、移位 ≥ 类型宽度进入不正常完成路径；需要回绕语义时使用 base `@wrap_add` / `@wrap_sub` / `@wrap_mul` 原语（`symbol.def` 0x00D–0x00F）。
- `as` 为显式承诺：窄化转换按位截断，行为固定；编译期可证明发生截断时产生诊断。

6.7 控制流原语（无需 `foreign` 声明，零分配、中性）：

- `@assert(cond: bool): void`（`symbol.def` `0x010`）：`cond` 为真时正常继续；为假时进入不正常完成路径，清理当前帧及调用链上的活跃拥有值并触发陷阱。
- `@exit(code: u8): void`（`symbol.def` `0x011`）：求值并保存 `code`（0–255），清理当前帧及调用链上的活跃拥有值并以该状态码终止进程，不返回。

## 七、所有权与能力

7.1 绑定上界：`let` 上界为 `Read`；`var` 上界为 `ReadWrite`。绑定只决定可重新赋值与能力上界，不决定单次访问实际建立的能力。

7.2 能力三态：

| 能力 | 语义 | 别名规则 |
|:---|:---|:---|
| `Read` | 只读借用 | 可并存多个 |
| `ReadWrite` | 独占读写借用 | 独占；存在期间不得有其他借用 |
| `Write` | 独占单次初始化借用 | 只由 `out` 通道产生 |

7.3 借用表达式：`&x` 缺省建立 `Read`；`&x:ReadWrite` 显式放大，且不得超过绑定上界。

7.4 能力型变：只允许 `ReadWrite` 收窄为 `Read`；任何升级拒绝。

7.5 单写排他：`ReadWrite` 活跃期间，原变量名与任何其他引用不可访问。

7.6 引用和切片是借用视图。复制引用只复制地址，复制切片只复制 `{ptr, len}`，副本遵守原 capability；均不复制所借用的值或转移析构责任。`&` 按 7.3 建立借用。函数静态引用是 `Copy` 值类型，`@copy` 合法，不参与能力系统与析构。

7.7 借用不越作用域；返回局部借用为拒绝形态。

7.8 禁止以引用或切片表达环与自引用；一律改用 `u32` 句柄 + 数组。

7.9 owning 值：赋值与传参即移动；移动后源不可再用。`Copy` 由编译器自动判定，无用户语法：标量、`bool`、`char`、视图与函数静态引用为 `Copy`；`[T; N]` 当 `T` 为 `Copy` 时为 `Copy`；`struct` 当全部字段为 `Copy` 且无自定义析构时为 `Copy`；`enum` 当全部 payload 类型为 `Copy` 时为 `Copy`；普通联合、`T?` 与 `T!E` 的 Copy 判定分别见 `type/union.md`、`type/option.md` 与 `type/result.md`；`T[]` 非 `Copy`（拥有堆）。实现 `Copy` 的类型不得直接或递归拥有需要自定义析构的资源。

7.10 析构：作用域出口按声明逆序执行确定性析构，恰好一次；允许显式 `@drop`。`var` 重新赋值前对旧值执行析构。`T[]` 的析构由编译器生成（释放堆）。

7.11 所有权动作（`@` 前缀原语调用，全部显式）：

| 动作 | 写法 | 语义 | 源状态 | 失败 |
|:---|:---|:---|:---|:---|
| `@move` | `@move(e)` | 转移唯一析构责任，零拷贝 | 失效 | 不失败 |
| `@copy` | `@copy(e)` | 位拷贝，仅 `Copy` 类型与视图 | 存活 | 不失败 |
| `@clone` | `@clone(e)` | 语义复制（仅非 `Copy` owning），可分配；类型为 `T!AllocError` | 存活 | 可失败 |
| `@drop` | `@drop(e);` | 立即析构恰好一次 | 失效 | 不失败 |

- `AllocError` 为固有错误 enum（分配失败）；base 期克隆契约由编译器合成（`T[]` 分配、struct 字段递归克隆）与标准库类型登记提供，用户不得自定义克隆行为。`@clone` 的域为**非 `Copy` 的 owning 类型**，但普通联合、`T?` 与 `T!E` 载体除外；作用于 `Copy` 类型、视图、普通联合、`T?` 或 `T!E` 为拒绝（使用 `@copy` 或移动 carrier）。
- 隐式 `@clone` / `@move` / `@drop` 全部拒绝；不得把 `@copy` 自动收窄为 `@clone`。
- `@move` / `@drop` 作用于非 owning（视图、函数静态引用）为拒绝。
- `f(@clone(e))`、`f(@copy(e))` 实参前缀、`@drop(a, b, c);` 批量、`.move()` 等链式动作均为糖，登记于 `sugar.md`，不在 base 提供。

7.12 `out` 槽位状态机（检查器事实，不得用占位 token 或零值伪装）：

| 状态 | 语义 |
|:---|:---|
| 空 | 声明后；不携带 `T`；唯一允许操作是以 `out name` 传入 `&T:Write` 参数 |
| 借出 | 调用检查完成至调用完成前；不得再次借用、读取、移动、重新声明 |
| 满 | 正常完成；携带唯一 owning `T`；不可直接读，只能经 `let v = @move(slot);` / `var v = @move(slot);` 提取 |
| 已消费 | 提取后；不再携带值，不参与作用域析构 |

- 同一调用的多个 `out` 实参必须引用不同槽位。
- 载体规则：含 `out` 调用只允许返回普通非 carrier 类型或 `T!E`。`T!E` 调用进入待判定状态：success 使全部关联槽位变满，error 使全部关联槽位回空；普通非 carrier 返回正常完成时全部关联槽位变满。返回 `T?`、普通联合或任何嵌套 carrier 的含 `out` 调用在当前 profile 拒绝。
- base 待判定载体的判定能力（`.is` / `if let` 转换视图）属 full 层；含 `out` 的 `T!E` 调用在 base 期须以 `?` 直接作用于该调用表达式传播，不得保存到绑定后判定。
- 合流规则：各前驱对同一槽位给出不同状态（满 / 空 / 已消费 / 待判定）即拒绝。
- 清理规则：error、`never`、陷阱等不正常完成路径离开前，必须析构已提交的输出 payload，并使关联槽位回空；该清理不得用零值写入、泄漏、双重析构或宿主异常替代。
- 禁止转发：被调方不得把 `out` 参数转给另一个函数、闭包、外部函数或内联汇编。

7.13 切片构造：`buf[a..b]` 半开区间；`..=` 闭区间不在 base 提供。`buf` 可为 `[T; N]` 或 `T[]`。

7.14 自动解引用：字段访问与索引位置上（方法接收者属 full 层），基址为引用或切片元素引用时自动解引用一层；多级必须显式 `*`；取地址 `&` 位置不自动；`Write` 通道不适用。

7.15 越界：编译期可证则拒绝；运行期越界进入不正常完成路径，并清理该路径上已提交的输出 payload。

7.16 `T[]` 固有操作：

- 索引读 `buf[i]`、索引写 `buf[i] = e`（需对 `buf` 具 `ReadWrite` 访问或 owning 可写 place）。
- 只读字段 `buf.len` / `buf.cap`，类型 `u64`。
- `&[T]` 只读字段 `.len`，类型 `u64`（取自胖指针 `{ptr, len}` 的 `len`）。
- 原语 `@push(x: &T[]:ReadWrite, e: T): void!AllocError`：追加元素，可触发重分配，失败为 `AllocError`。
- 原语 `@len(x: &[T]): u64`：返回切片的元素数（读取胖指针的 len 字段，零分配，中性）。
- 字面量 `[e0, e1, …]` 与空 `[]`；元素类型由上下文定型。
- `[T; N]` 的编译期长度 `N` 不经 `@len` 取得——它是类型的一部分，由 `const` 求值或类型推导访问；`@len` 只作用于运行期 `&[T]` 切片。
- 其余操作（`pop`、`insert`、`resize` 等）为 full 层标准库。

## 八、模块

8.1 平面模块：一个文件一个模块，模块名与路径一致。

8.2 依赖为有向无环图；循环依赖为拒绝形态。

8.3 导入导出：显式 `import` / `export`；未导出项不可被外部引用。

8.4 顶层绑定：base 期模块顶层只允许 `const`；顶层 `let` / `var` 推迟至 full 层登记。

## 九、外部接口

9.1 外部函数以 `foreign` 声明，调用约定见 `../target/abi-win.md` / `abi-linux.md`。

9.2 base 期用户可声明的 `foreign` I/O 服务由[外部接口规格](foreign.md)第三节登记（保留在外部 ABI 层，不进入 `@` 原语闭集）。进程退出与断言已上移为语言级控制流原语 `@exit(code: u8): void` 与 `@assert(cond: bool): void`（见 6.7）；原 `foreign exit` 与 `foreign assert` 仅作 T1 冻结 Seed 与存量夹具兼容保留。堆分配和释放属于运行时内部服务。签名、失败行为与种子宿主的单独登记见 [外部接口规格](foreign.md) 第三节。

9.3 `Write` 不得传给外部边界；外部输出指针必须由独立的 `unsafe.md` / `foreign.md` 契约登记。

受限点火参数与文件服务由 `../proc/host.md` 单独登记，属于种子宿主扩充；不开放任意 foreign 符号。

## 十、资源与确定性

10.1 语义完全确定：无未定义行为，求值顺序、遍历顺序、错误顺序均确定。

10.2 资源上限（输入规模、步数、内存、递归深度）由实现登记，纳入门禁 `../proc/gate.md`。

10.3 不正常完成路径必须可判定，并在离开前完成已提交资源的清理。

## 十一、base 排除清单

11.1 以下不属于 base，只可在 full 层经 `sugar.md` 降级或独立 full 内核规格引入：用户定义泛型与单态化、闭包、interface / impl、编译期函数求值（CTFE）、浮点、裸指针、`unsafe`、内联汇编、并发与原子操作、动态派发、宏、异步、模块级泛型。const 整数折叠（`const.md` 2.8）不是 CTFE，属 base。

11.2 以下明确推迟至 full 层：owning 字符串 `string` 与 `&string`、`tuple`、普通 `A | B`、`T?` / `null` / `?.` / `??` / `if let`、`is` 联合成员测试、`T!E` 的手动恢复（`.catch` / `.then` / `.or` / `.unwrap`）、通用 `Error` 标记接口、`match` 作用于错误集或普通联合、`.unwrap()` 显式中止、`..=` 闭区间、多层自动解引用、别名绑定、`@clone` / `@copy` 实参前缀、批量 `@drop`、链式动作（`.move()` 等）、接口语法（`implements` / `impl` / 约束）、`loop`、顶层 `let` / `var`、`T[]` 的扩展操作（`pop` / `insert` / `resize` 等）、无捕获匿名函数 `(params) => body`（S-21）、字节字面量 `b'...'` / `b"..."`、原始字符串 `r"..."`、模板字符串 `` `...` ``（S-24）。

11.3 无捕获匿名函数（S-21）不是闭包类型；它产出 `&function(P): R`（T-13），属 full 层糖，不违反 11.1 的闭包排除。body 只能引用参数与模块级名字；引用外围局部为拒绝（`sugar.md` SU-8）。

11.4 `ref`、`val` 不作为关键字引入；`&` 与 `let` / `var` 分别为引用与绑定的唯一记号。不引入 `Ok` / `Err` / `Some` / `None` 构造器。

11.5 base 实现不得接受以上形态；出现即拒绝。
