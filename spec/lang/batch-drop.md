# 批量析构语句

## 元信息

- 名称：批量 @drop（[S-7](sugar.md#s-7-批量-drop)）
- 级别：full
- 状态：草案
- 依赖：[基座](base.md)、[解析](parse.md)、[规格状态](../proc/status.md)

## 语法形式

```text
BatchDropStmt ::= '@drop' '(' Expr ',' Expr (',' Expr)* ')' ';'
```

## 语义规定

- 全部操作数从右向左逐一求值并析构，每个操作数遵守单参 `@drop` 的 place、生命周期及所有权规则；不预求值，不合并重复操作数。

## 脱糖目标

- `@drop(a, b, c);` 在同一块内原位替换为 `@drop(c); @drop(b); @drop(a);`；诊断依然定位原操作数。

## 约束与限制

- 单参写法仍属于基座；零参、尾逗号和值位置不属于本规则。仅在隔离的待确认候选中评估；min 仍拒绝批量，正式启用须通过 [确认门槛](../proc/status.md#二状态迁移条件)。

## 拒绝形态

- 非法参数形态沿用基座解析拒绝；任一操作数违反单参 `@drop` 约束时沿用对应的基座拒绝。
