# effect

## 元信息

- 名称：effect（静态效果标注与调用图传播）
- 级别：full
- 状态：草案
- 依赖：`base.md`、`foreign.md`、`symbol.md`、`unsafe.md`、`asm.md`、`../ir/mir.md`

## 一、范围与定位

1.1 本文规定 full 层静态效果契约闭集、调用图固定点传播规则、跨模块 `.iface` 摘要传递及外部 `foreign` 效应证明机制。

1.2 Yak 的效果系统是**零运行期开销的编译期静态闭集契约**，直接推广 `base.md` 5.11 与 `../ir/mir.md` 6.5 的 `#`（`no_alloc`）固定点模型。

1.3 Yak **不引入**用户自定义代数效应（algebraic effects）、运行时效应处理器（handler）或续体栈切换（EF-3）。

## 二、静态效果闭集

| 效果名 | 表面记法 | 语义（对函数及其可达调用图成立） | 阶段 |
|:---|:---|:---|:---|
| `no_alloc` | `#`（简写）或 `@effect(no_alloc)` | 不增加 Yak 运行时堆分配（允许析构与堆释放） | base / full |
| `no_trap` | `@effect(no_trap)` | 不触发算术溢出、除零、移位越界、索引/切片越界、`assert` 或 `.unwrap()` 陷阱 | full |
| `no_io` | `@effect(no_io)` | 不调用宿主 I/O 服务（`read`/`write`/文件/网络）或 `@volatile_*` 外设访存 | full |

2.1 `no_alloc` 已有唯一简写 `#`（`base.md` 5.11）；`@effect(no_alloc)` 与 `#` 语义完全等价，不得在同一声明重复矛盾标注。

2.2 效果闭集只增不改；新增效果须先登记本文与 `.iface` 预留 flags 位（`symbol.md` 10.8）。

## 三、传播与固定点验证

3.1 **本地分类**：对每个非泛型具体函数（含单态化后的泛型实例与合成匿名函数），编译器按 MIR 指令表计算每项效果的 `local_safe(F, E)`：
- `no_alloc`：严格复用 `../ir/mir.md` 6.5 分类表；
- `no_trap`：出现可陷阱指令（`mir.md` 4.2/4.3/4.6/4.9/4.13 `trap`、`call_service` 或 `.unwrap()` 失败路径）且无法在编译期静态证明永不触发时为 false；回绕算术 `@wrap_*` 与经静态边界证明消除陷阱的访问为 true；
- `no_io`：出现 I/O 外部服务调用、`@volatile_*` 或未标注 `nomem` 的 `@asm` 时为 false。

3.2 **SCC 逆拓扑固定点**：沿用 `../ir/mir.md` 6.5 规则 3：将模块内直接调用图压缩为强连通分量（SCC）DAG，按 caller→callee 逆拓扑序求值。无出边且分量内全员 `local_safe=true` 的递归 / 互递归 SCC 判定为 true。

3.3 **间接调用与动态分派**：在未声明对应效果约束的 `&function` 间接调用或动态接口 `&Interface` 调用位点，效果不可验证，结果为 false；带声明效果契约的函数到达此类调用即按 EF-2 拒绝。

3.4 **泛型函数**：泛型声明本身不预先断言效果成立；对标注效果的泛型函数，在 full 单态化（`generic.md` 六）后的每个具体实例上独立执行固定点验证。

## 四、外部边界与跨模块摘要

4.1 **`.iface` 跨单元传递**：每个导出非泛型函数的各效果固定点结果写入 `ExportRecord.flags` 预留位（bit 0 固定为 `no_alloc`，后续位按 `symbol.md` 10.8 演进登记）；导入方仅读取已校验接口标志，不重扫依赖源码（EF-4）。

4.2 **外部 `foreign` 效应契约**：呼应 `foreign.md` 2.5，对 full 层开放的任意外部 C-ABI `foreign` 声明，编译器无法穿透目标二进制验证其内部行为；若需纳入 `#` / `no_trap` / `no_io` 调用图，必须在 `unsafe` 信任边界内显式声明 `@effect(...)` 契约，由调用方/绑定维护者承担静态正确性责任（EF-5）。

## 五、拒绝形态

| 编号 | 条件 |
|:---|:---|
| EF-1 | 声明静态效果契约的函数在其可达调用图中包含违反该效果的操作或目标 |
| EF-2 | 静态效果验证范围内存在不可验证的间接函数调用或无效果约束的动态接口调用 |
| EF-3 | 使用未登记的效果名称，或试图声明用户自定义代数效应 / 动态处理器 |
| EF-4 | 依赖接口 `.iface` 缺失所需效果标志或与声明契约冲突 |
| EF-5 | 在未授权上下文伪造外部 `foreign` 效应契约，或同一声明对同一效果重复矛盾标注 |
