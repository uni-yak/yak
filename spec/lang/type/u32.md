# u32

## 元信息

- 名称：u32
- 级别：base
- 状态：草案
- 依赖：`../base.md`、`../lex.md`、`../owner.md`、`../layout.md`、`../symbol.md`

## 定义

- 取值范围：0 .. 2³²−1（0 .. 4294967295）
- 内存布局：4 字节，无符号，小端序；对齐 4
- 默认值：无；绑定必须显式初始化

## 字面量

- 形式：十进制、`0b` / `0o` / `0x` 前缀；后缀 `u32`（`lex.md` 8.1）
- 拒绝：超出 0..4294967295 的字面量（L-4）

## 操作

- 允许：`+ - * / %`、`< <= > >= == !=`、`& | ^ << >>`、一元 `-`
- 禁止：逻辑运算（`&& || !` 属 `bool`）

## 转换

- 隐式：无
- 显式 `as`：→ 任意整数（窄化按位截断，宽化零扩展）；→ `bool` 不允许；→ `char`（须为合法 Unicode 标量值，命中代理对区或超出 U+10FFFF 拒绝，见 `char.md`）
- 溢出行为：算术溢出、除零、移位 ≥ 32 进入不正常完成路径（陷阱）；需回绕语义时使用 `@wrap_add` / `@wrap_sub` / `@wrap_mul`

## 所有权

- 复制 / 移动：Copy；普通值位置复制，源保持 live（`owner.md` 2.4）；`@move` 不适用
- 借用形态：`&u32:Read` / `&u32:ReadWrite`
- 析构：无用户可观察析构

## 拒绝形态

| 编号 | 条件 | 码 |
|:---|:---|:---|
| L-4 | 字面量超出 0..4294967295 | E1004 |
