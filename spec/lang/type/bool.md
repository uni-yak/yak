# bool

## 元信息

- 名称：bool
- 级别：base
- 状态：草案
- 依赖：`../base.md`、`../lex.md`、`../owner.md`、`../layout.md`、`../symbol.md`

## 定义

- 取值范围：`true` / `false`
- 内存布局：1 字节；`false` = 0，`true` = 1；写入须归一为 0 或 1；对齐 1
- 默认值：无；绑定必须显式初始化

## 字面量

- 形式：`true` / `false`（保留字，`lex.md` 8.4）
- 拒绝：整数字面量在 `bool` 位置定型（`lex.md` 8.2 无默认宽度）

## 操作

- 允许：`&& || !`（短路求值，左操作数为假 / 真时不求值右操作数）、`== !=`
- 禁止：算术（`+ - * / %`）、位运算（`& | ^ << >>`）、序比较（`< <= > >=`）、一元 `-`

## 转换

- 隐式：无
- 显式 `as`：→ 任意整数 不允许；← 任意整数 不允许
- 溢出行为：不适用

## 所有权

- 复制 / 移动：Copy；普通值位置复制，源保持 live（`owner.md` 2.4）；`@move` 不适用
- 借用形态：`&bool:Read` / `&bool:ReadWrite`
- 析构：无用户可观察析构

## 拒绝形态

| 编号 | 条件 |
|:---|:---|

| — | 对 `bool` 施行算术或位运算 |
