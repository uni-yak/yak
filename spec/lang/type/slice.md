# slice

## 元信息

- 名称：slice（`&[T]` 切片视图）
- 级别：base
- 状态：草案
- 依赖：`../base.md`、`../parse.md`、`../layout.md`、`../owner.md`、`../symbol.md`、`array.md`、`ref.md`

## 定义

- 取值范围：连续元素区间视图，胖指针 `{ptr:u64, len:u64}`，`size = 16`，`align = 8`（`layout.md` 四）。
- 不拥有目标；不触发析构；复制只复制 `{ptr, len}`。
- `&[T]:Read`（默认，可并存）；`&[T]:ReadWrite`（独占）。
- 零长切片可使用 `ptr=0`；其元素访问始终越界（`layout.md` 4.2）。
- 默认值：无；绑定必须显式初始化。

## 字面量

- 形式：无独立字面量；由数组或动态数组取区间产生：`&a[a..b]`（半开；`..=` 闭区间为 full，`base.md` 7.13）。
- 字符串字面量类型为 `&[u8]`，指向静态存储（`lex.md` 8.9、`base.md` 4.2）。
- 拒绝：从已 `moved` / `dropped` 的源取切片。

## 操作

- 允许：索引 `s[i]`（编译期可证越界为拒绝；运行期越界进入不正常完成路径，`base.md` 7.13）。
- 允许：子切片 `&s[a..b]`（`..=` 为 full）。
- 禁止：隐式 `==` / `!=`；隐式转换；`as`。
- 元素计数：`&[T]` 经 `.len` 字段（`base.md` 7.16）；`T[]` 另有 `.cap`。

## 转换

- 隐式：无
- 显式 `as`：无
- 溢出行为：不适用

## 所有权

- 复制 / 移动：视图为 Copy 值表示；复制不转移或复制目标 owning 值（`owner.md` 3.6）；`@move` / `@drop` 不适用。
- 借用形态：`&[T]` 自身即视图；不得再取 `&(&[T])` 作字段 / payload / 元素 / 返回（`base.md` 4.4）。
- 析构：无。

## 拒绝形态

| 编号 | 条件 |
|:---|:---|
| — | `&[T]` 出现在字段 / payload / 元素 / 泛型实参 / 返回位（`base.md` 4.4） |
| — | 运行期索引越界（进入不正常完成路径） |
| — | 切片逃逸其源的生命周期（`owner.md` 3.x） |
