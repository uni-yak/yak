# i64

## 元信息

- 名称：i64
- 级别：base
- 状态：草案
- 依赖：`../base.md`、`../lex.md`、`../owner.md`、`../layout.md`、`../symbol.md`

## 定义

- 取值范围：−2⁶³ .. 2⁶³−1（−9223372036854775808 .. 9223372036854775807）
- 内存布局：8 字节，有符号，二进制补码，小端序；对齐 8
- 默认值：无；绑定必须显式初始化

## 字面量

- 形式：十进制（可带 `-`）、`0b` / `0o` / `0x` 前缀；后缀 `i64`（`lex.md` 8.1）
- 拒绝：超出 −9223372036854775808..9223372036854775807 的字面量（L-4）

## 操作

- 允许：`+ - * / %`、`< <= > >= == !=`、`& | ^ << >>`、一元 `-`
- 禁止：逻辑运算（`&& || !` 属 `bool`）

## 转换

- 隐式：无
- 显式 `as`：→ 任意整数（窄化按位截断，宽化符号扩展）；→ `bool` / `char` 不允许
- 溢出行为：算术溢出、除零、`i64::MIN / -1`、移位 ≥ 64 进入不正常完成路径（陷阱）；需回绕语义时使用 `@wrap_add` / `@wrap_sub` / `@wrap_mul`

## 所有权

- 复制 / 移动：Copy；普通值位置复制，源保持 live（`owner.md` 2.4）；`@move` 不适用
- 借用形态：`&i64:Read` / `&i64:ReadWrite`
- 析构：无用户可观察析构
