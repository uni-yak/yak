# tuple

## 元信息

- 名称：tuple（元组）
- 级别：full
- 状态：草案
- 依赖：`../base.md`、`../sugar.md`、`../layout.md`、`../owner.md`、`struct.md`

## 定义

- 取值范围：
  - `(T0, T1, ..., Tn)` 为有序异构积类型，元素个数满足 `n + 1 >= 2`。
  - 不存在空元组 `()` 与单元素元组 `(T,)`：空返回使用 `void`（`void.md`），括号内单表达式仅作分组，避免引入零大小可存储对象（`../layout.md` 2.5）。
  - 每个元素类型 `Ti` 必须是可存储的具体 owning 类型；视图（`&T`、`&[T]`）、`void`、未加括号的 carrier 组合与未实例化类型参数不得作为元素类型。
- 内存布局：
  - 按 `../sugar.md` S-11 脱糖为编译器合成的匿名 `struct { _0: T0, _1: T1, ... }`；遵循 `../layout.md` 第六节与 9.3 的声明顺序 struct 布局，禁止自动字段重排。
  - 字段间与尾部 padding 不属于可读值，不参与比较或语义复制（`../layout.md` 6.3–6.4）。
- 默认值：无。所有元素在构造时必须显式提供。

## 字面量

- 形式：
  - 构造写作 `(e0, e1, ...)`，按从左到右顺序依次求值各元素表达式（`../base.md` 6.5）。
  - 允许尾随逗号，例如 `(e0, e1,)`。
- 拒绝：
  - 空元组字面量 `()` 或单元素元组字面量 `(e,)`（TP-1）。
  - 用户直接书写合成字段名 `_0` / `_1` 声明结构体或替代位置索引语法。

## 操作

- 允许：
  - 位置索引读取与写入：`t.0`、`t.1`、…，下标必须为编译期十进制非负整数常量且严格小于元组维度。
  - 解构绑定（由 `sugar.md` 后续登记具体模式语法前，通过位置索引访问）。
  - 结构体同构的借用视图：对整个元组建立 `&T` / `&T:ReadWrite`，并在单层自动解引用后读取或写入元素。
- 禁止：
  - 使用运行期整数表达式对元组进行索引（如 `t[i]`，TP-3）。
  - 对元组使用比较运算符，除非未来经 `interface` 显式实现。

## 转换

- 隐式：无。两个元组类型等价当且仅当维度相同且对应位置元素类型逐一相同（结构等价）。
- 显式：`as` 不得用于元组与命名 `struct` 之间的类型转换。
- 溢出行为：无。

## 所有权

- 复制 / 移动：当且仅当全部元素类型均为 `Copy` 时，元组为 `Copy`（与 `../base.md` 7.9 的 `struct` 规则一致）。非 `Copy` 元组按值赋值或传参执行整值移动；调用 owning 参数须显式写 `@move(e)`。
- 借用形态：遵守 `../owner.md` 第三节借用规则；当前保守模型禁止对非 `Copy` 元组元素执行部分移动（TP-4）。
- 析构：非 `Copy` 元组在作用域出口、覆盖或显式 `@drop` 时，按元素下标逆序（从末元素到第 0 元素）恰好析构一次（`../owner.md` 6.2）。
- 克隆：当且仅当全部非 `Copy` 元素具备完整递归克隆契约时，允许 `@clone(e)`，返回 `(T0, ...)!AllocError`；中途分配失败时逆序析构已构造元素。

## 拒绝形态

| 编号 | 条件 |
|:---|:---|
| TP-1 | 构造 0 元或 1 元元组 |
| TP-2 | 元组元素类型为视图、`void`、非法载体或未实例化类型参数 |
| TP-3 | 元组下标越界或使用非编译期整数常量索引 |
| TP-4 | 对非 `Copy` 元组执行部分移动，或对含非 `Copy` 元素的元组使用 `@copy` |
