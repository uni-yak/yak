# f64

## 元信息

- 名称：f64（双精度浮点占位）
- 级别：full
- 状态：草案-可实施
- 依赖：无

## 定义

- f64 在 base 期不激活：`symbol.def` 的预留编号不激活此类型，词法与类型层不得接受浮点类型名或浮点字面量。
- 本规格只规定 base 期对浮点形态的拒绝边界；浮点数值语义、布局、运算与 ABI 未定义，待 full 层独立规格冻结，不在本文件授予实现权限。

## 拒绝形态

| 编号 | 条件 | ErrorCode |
|:---|:---|:---|
| F64-1 | base 期出现浮点类型名 `f64` 或浮点字面量 | E1007 / E5002 |
