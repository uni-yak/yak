# generic

## 元信息

- 名称：generic（泛型与编译期单态化）
- 级别：full
- 状态：草案
- 依赖：`base.md`、`parse.md`、`lex.md`、`name.md`、`symbol.md`、`sugar.md`

## 一、范围

1.1 本文规定 full 层用户泛型的声明、类型实参、显式调用、类型推导、接口约束与单态化。

1.2 base 期禁止用户定义泛型；本文件只在 full 层生效（`base.md` 11.1）。

1.3 本文使用 `interface` 作为 Yak 的接口约束名称；不引入其他语言的混入式能力约束体系或术语。

1.4 泛型本身不产生运行期类型参数；编译期单态化后进入 MIR 的是具体实例。`T!E` 的 `E` 在泛型声明期必须是已实例化名义 enum，不得以类型参数作为 `E`；`T!E` 的 `T` 与 `T?`、普通联合的成员可使用类型参数，但实例化前不得进入布局、MIR、YSM 或 ABI。

## 二、路径与泛型分隔符

2.1 `::` 是编译期路径分隔符，用于模块、类型、函数与 enum 标签的限定路径：

```yak
工具::文本::写行
工具::数据::对
工具::颜色::运行状态::故障
```

2.2 `.` 是实例成员访问符，只用于字段与方法接收者：

```yak
记录.代码
缓冲区.长度()
```

2.3 `::` 与 `.` 不互换：`状态::故障` 是 enum 标签路径；`状态值.故障` 是实例成员访问。

2.4 类型泛型实参使用 `<...>`：

```yak
工具::数据::对<i64, bool>
```

2.5 表达式位置的显式泛型调用使用 `::<...>`，避免与 `<` / `>` 比较运算混淆：

```yak
工具::泛型::原样::<i64>(@move(输入))
```

2.6 `::<...>` 只能紧跟可调用的限定路径；不得出现在字段访问、普通变量或非泛型函数之后。

## 三、泛型声明

```ebnf
GenericParams ::= '<' GenericParam { ',' GenericParam } '>'
GenericParam  ::= Ident [ 'implements' '(' InterfacePathList ')' ]
InterfacePathList ::= InterfacePath { ',' InterfacePath }
InterfacePath ::= QualifiedPath
GenericArgs   ::= '<' Type { ',' Type } '>'
QualifiedPath ::= Ident { '::' Ident }
```

3.1 泛型函数：

```yak
export function 原样<T>(move value: T): T {
    return value;
}
```

3.2 泛型 struct：

```yak
export struct 对<左, 右> {
    第一: 左,
    第二: 右,
}
```

3.3 泛型 enum：

```yak
export enum 结果<T> {
    成功(T),
    失败,
}
```

标签 `成功` 与 `失败` 是该 enum 的用户声明成员，不是语言预置名称。

3.4 泛型参数名是声明产生的普通类型参数名；`T`、`左`、`右` 没有特殊内建意义。

3.5 `implements(...)` 是 full 层接口约束语法；括号明确约束列表边界。接口声明与实现规则由接口规格单独规定。接口约束不改变泛型的单态化模型。

3.6 同一泛型参数不得重复声明；同一参数的接口约束不得重复。

3.7 每个泛型声明创建一个 generic `ScopeId`；每个泛型参数是该作用域内 `DefKind=generic_parameter` 的 `DefId`。该作用域在函数参数、enum payload 或 struct 字段类型解析前进入，在所属声明体解析结束后退出。实例化后，类型参数引用被具体类型替换；未实例化 `NameId`、`ScopeId` 或 `DefId` 不得进入具体 MIR、YSM 或 ABI。

## 四、泛型类型使用

4.1 类型位置直接使用 `QualifiedPath` 加 `GenericArgs`：

```yak
let pair: 工具::数据::对<i64, bool> = ...;
let result: 工具::结果::结果<u64> = ...;
```

4.2 泛型实参可以是：

- 固有类型：`i64`、`bool`；
- 用户类型：`工具::数据::记录`；
- 已实例化类型：`工具::数据::对<i64, bool>`；
- 函数静态引用类型：`&function(&i64): void`。

4.3 视图类型是否可作为泛型实参仍受 `base.md` 4.4 与 full 接口规则限制；`T!E` 的 `T` 可出现类型参数但 `E` 必须为已实例化名义 enum（见 `type/result.md`）；ErrorSet 与普通联合是否可作泛型实参分别受 `type/result.md` 与 `type/union.md` 的位置限制；base 期用户泛型整体禁用。

## 五、泛型函数调用

5.1 类型实参可由调用实参与目标类型推导：

```yak
function 演示推导(): i64 {
    let 输入: i64 = 42;
    let 输出: i64 = 工具::泛型::原样(@move(输入));
    return 输出;
}
```

此调用推导 `T = i64`。

5.2 不能唯一推导或需要固定实例时，显式写 `::<...>`：

```yak
function 演示显式(): i64 {
    let 输入: i64 = 42;
    let 输出: i64 = 工具::泛型::原样::<i64>(@move(输入));
    return 输出;
}
```

5.3 多个类型实参：

```yak
let 输入: 对<i64, bool> = ...;
let 输出: 对<i64, bool> = 工具::泛型::原样::<对<i64, bool>>(@move(输入));
```

5.4 泛型函数的 owning 参数仍按 `owner.md` 2.3 在调用点显式写 `@move(e)`；参数声明不使用 `move` 前缀，泛型不改变所有权规则。

5.5 `&T`、`&T:ReadWrite` 等访问参数仍按 `base.md` 5.2 处理；类型参数不能绕过能力检查。

## 六、推导与单态化

6.1 类型推导只在编译期进行；无法得到唯一类型实参时拒绝（G-1）。

6.2 每个合法调用点收集具体类型实参并生成单态化实例：

```text
原样<T> + T=i64
  → 原样<i64>
  → 具体 MIR
  → 目标代码
```

6.3 单态化实例不建立新的用户名字；实例身份由泛型声明实体、类型实参序列与目标 profile 的确定摘要构成。

6.4 同一编译单元内相同实例只生成一次；跨单元实例由接口摘要与目标链接规则去重。

6.5 单态化实例的链接修饰名包含声明路径与类型实参摘要；源代码路径仍以 `::` 表示，目标修饰格式由 `../target/emitter.md` 规定。

6.6 泛型体的语义检查分两步：声明体检查通用规则，实例化后检查具体类型约束与布局。

## 七、接口约束（full 草案）

7.1 约束示例：

```yak
export function 左侧较大<T implements (可比较)>(左: &T, 右: &T): bool {
    return *左 > *右;
}
```

7.2 `implements` 后的每个名称均为 `InterfacePath`，可使用模块限定路径：

```yak
function 合并<T implements (工具::接口::可合并)>(move a: T, move b: T): T {
    return 工具::接口::合并(@move(a), @move(b));
}
```

7.3 接口约束只提供编译期可验证的操作集合；不自动引入任何成功、失败或可选值标签。标签必须由 enum 声明。

7.4 动态接口视图、函数指针表与接口对象所有权规则属于 full 接口规格；接口对象不是普通字段访问。

## 八、路径解析规则

8.1 `QualifiedPath` 的每段均为编译期名字；最后一段在当前语法位置决定其类别：类型、函数、enum、enum 标签或模块。

8.2 `import A::B::C;` 将完整路径解释为模块导入路径；`A::B::C::函数` 在表达式位置解释为函数路径。

8.3 `A::B::类型<...>` 在类型位置解释为泛型类型路径；`A::B::函数::<...>(...)` 在调用位置解释为显式泛型调用。

8.4 `EnumPath<Args>::Variant` 只在 pattern 或 enum 构造位置解释为标签路径；最后一个 `::Ident` 为标签，其前缀为已实例化 enum 类型。`value.field` 始终解释为实例成员访问。

8.5 `::` 不表示运行期指针、字段或方法访问；`.` 不表示模块、类型或 enum 的静态路径。

## 九、拒绝形态

| 编号 | 条件 |
|:---|:---|
| G-1 | 泛型实参无法唯一推导 |
| G-2 | 泛型参数重复声明 |
| G-3 | 泛型实参数量与参数数量不一致 |
| G-4 | `::<...>` 用于不可调用路径 |
| G-5 | 接口约束重复或无法解析 |
| G-6 | 泛型实例不满足接口约束 |
| G-7 | 泛型实例布局或所有权规则不满足 |
| G-8 | 泛型递归实例化超过登记上限 |
| G-9 | 将 `.` 成员访问写作 `::` 或将静态路径写作 `.` |
| G-10 | 使用未声明的类型参数 |
