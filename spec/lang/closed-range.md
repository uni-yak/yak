# 闭区间切片

## 元信息

- 名称：闭区间切片（[S-3](sugar.md#s-3--闭区间)）
- 级别：full
- 状态：草案
- 依赖：[基座](base.md)、[解析](parse.md)、[常量](const.md)、[规格状态](../proc/status.md)

## 语法形式

```text
ClosedSlice ::= Expr '[' Expr '..=' Expr ']'
```

## 语义规定

- 端点必须为基座半开切片可接受的整数类型。闭区间上界在其原整数类型中进行受检加一，求值一次；后续边界检查、capability 和清理均沿用基座半开切片。

## 脱糖目标

- `buf[a..=b]` 原位替换为 `buf[a..(b+1)]`，`1` 采用 `b` 的整数类型；保留原上界位置供溢出诊断。

## 约束与限制

- 不允许省略端点，不新增区间值类型。仅在隔离的待确认候选中评估；min 仍拒绝该记号，正式启用须通过 [确认门槛](../proc/status.md#二状态迁移条件)。

## 拒绝形态

- SU-5：上界加一编译期可证明上溢时拒绝；不能静态证明时通过基座受检整数加法在运行时陷阱，不环绕。基座切片越界规则独立适用。
