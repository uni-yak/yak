# spec/tpl

## 职责

存放规格文档的**写作模板**，保证全部规格（类型、语法特性）风格统一、章节一致。

## 结构

- `type.md` —— 数据类型规格模板：`spec/lang/type/` 下每份文档依此成文
- `syntax.md` —— 语法特性规格模板：`spec/lang/` 下每份语法规格依此成文

## 边界

- 本目录只放模板，不放具体规格内容。
- 模板一经修订，需同步检查已成文规格是否满足新结构。

## 使用约定

- 新规格必须复制模板首部"元信息"字段，含级别（base / full）与状态（确认 / 草案-可实施 / 草案 / 缺失）。
- 手册式：只做规定，不写动机、示例解释与教程。
