# pkg

## 职责

语言标准库：语言产品的一部分，随编译器发布，不属于任一编译器的私有代码。

## 结构

- `string/` —— 字符串与构造器
- `buf/` —— 可增长字节缓冲
- `alloc/` —— 堆分配
- [io/](io/README.md) —— 标准输入与标准输出，当前通过显式编译与链接使用
- `math/` —— 整数数学

## 边界

- 与 `../runtime/`：标准库依赖运行时，运行时不依赖标准库。
- 与 `../spec/lang/type/`：类型的语言规定在 `spec`，此处是**实现**。

## 约定

- 每个模块自带测试，测试资产放 `../test/ok/` 与 `../test/bad/` 对应分组。
- 库不得依赖编译器私有行为。
