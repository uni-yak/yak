# test

## 职责

测试资产集中存放处，按用途分门别类。

## 结构

- `ok/` —— 正例语料：按语言特性分组，每组含期望输出/期望行为
- `bad/` —— 负例语料：每条拒绝规则至少一案，按规则分组
- `gate/` —— 门禁用例：确定性、收敛性、资源预算
- `perf/` —— 性能基准：对照 C 基线
- `unit/` —— 组件单元测试：`seed` 解释器、发射器解析等

## 边界

- 与本作用处的关系：这里消费规格产出验证；规格变更必须同步更新对应案例。
- 与 `../examples/`：示例面向展示，测试面向判定。

## 约定

- 每个案例自带期望结果说明，禁止"跑过就算通过"。
- 负例必须指明对应规格中的拒绝形态编号。
- 全部测试绕过 `../tmp/` 运行，不污染源码目录。
