# seed/test

## 入口

```bash
bash seed/test/run_tests.sh [binary]
```

```powershell
./seed/test/run_tests.ps1 [-SeedPath <binary>]
```

默认只使用 `seed/out/yak-seed.exe`。显式指定不存在的二进制必须失败，不回退到默认产物。单例超时为 20 秒，超时不视为预期陷阱。

单独执行一个用例可运行 `bash seed/test/run_one.sh <测试文件>`：匹配预期时退出 0，不匹配时退出 1，参数错误退出 2。每次运行使用独立临时目录。运行 `bash seed/test/test_run_one.sh` 可验证该入口的状态码、陷阱和并发隔离。

在锁定版本的 MSYS2 UCRT64 中运行 `bash seed/test/test_build.sh`，可独立验证构建锁、工具版本拒绝、安装目标检查及冻结发布回滚。该测试在临时副本注入故障，不改动正式产物。

## 用例与判定

Yak 用例由两个运行器自动枚举，数量不作为硬编码通过条件；另有 `value_test.c` 原生测试。

成功例要求退出 0 且 stderr 为空；计算结果用真正的 assert 校验。`expected_stdout` 比较文本输出，统一去除 CR 和末尾换行。负例要求退出 1 且 stderr 含字面量 `expected_trap`；崩溃和超时均失败。`mem_limit` 配置该进程的有效载荷预算。

| 标记 | 含义 |
|:---|:---|
| `// module: name=relative-path` | 显式模块绑定，路径相对本测试目录 |
| `// input: name=relative-path` | 只读输入登记 |
| `// output: name` | 运行器专用临时输出登记；陷阱后必须不存在 |
| `// output_existing: name=relative-path` | 验证已有输出不会被覆盖 |
| `// arg: text` | 传给 Yak 的一个独立参数 |
| `// expected_file: name=text` | 完整比较输出文件的文本字节 |
| `// expected_file_hex: name=hex` | 完整比较二进制输出 |

`common.sh` 供 bash 运行器与构建脚本共用，避免冻结门禁和日常测试使用不同判定。PowerShell 运行器独立执行同一标记协议并分别捕获 stdout/stderr。

`fixtures/` 仅存放模块依赖与输入夹具，包含有意非法 UTF-8 的负例。测试不会把未来设计或未执行的样例当作通过证据。

`value_test.c` 独立于 Yak 解析，验证分配对齐、realloc 内容与预算、嵌套 clone 失败回滚、四种整数宽度的无符号除法、调用实参传播时的 out 槽位回滚、切片下界传播时跳过高界求值、回绕原语实参传播短路和统一回收。正式构建分别用 GCC/Clang 编译并运行它。

min 词法组件在 seed 下验证；目标编译流水线已能经 `tools/link.sh` 单源或多源（依赖在前、根在后）产出可执行文件，端到端断言见 `tools/test_link_e2e.sh`（含顶层全局常量视图、导入签名校验、数组常量原生读回与多单元 `call_far` 链接）。JSONL 诊断接入、非 ASCII 名称分类、模块图自动发现与 YSM 依赖节等剩余边界仍见 ROADMAP。参考组件通过不等于 T1 完成或语言规格确认。
