# seed/src

## 职责

实现解释器的词法、解析、值表示、树遍历执行与点火宿主。语言契约位于 `../../spec/lang/`，受限宿主契约位于 `../../spec/proc/host.md`。

## 文件

| 文件 | 职责 |
|:---|:---|
| main.c | Unicode 命令行入口、预算配置和解释驱动 |
| host.c | 参数、文件授权登记、二进制输入输出和输出回滚 |
| module.c | 显式模块绑定、文件身份、依赖图与可见性查询 |
| lex.c | UTF-8 校验、整数/字符/文本字面量和记号流 |
| parse.c | 递归下降与 Pratt 表达式解析、AST 索引和容量检查 |
| eval.c | 表达式、函数调用与模块执行 |
| eval_env.c、eval_env.h | 求值环境、绑定和借用生命周期及内部接口 |
| eval_type.c、eval_type.h | 求值类型身份、值定型和共享上下文 |
| eval_place.c、eval_place.h | 左值投影、借用检查与赋值位置刷新 |
| eval_builtin.c、eval_builtin.h | 内建原语分派与共享求值接口 |
| eval_stmt.c、eval_stmt.h | 语句求值、控制流信号和临时借用释放 |
| value.c | 值复制/移动/析构、数组和 clone 回滚 |
| integer.c | 整数定型、有符号/无符号运算及溢出检查 |
| memory.c | 对齐分配、重新分配、活内存预算与统一回收 |
| runtime.c | 步数预算、带源码位置的陷阱和统一退出 |
| foreign.c | 固定签名校验与标准流/受限宿主服务分派 |
| yak.h | 内部数据结构和组件接口 |

## 生命周期

AST 节点以索引引用；递归解析后重新按索引定位节点，不持有跨扩容指针。容量超限和解析深度超限失败关闭。

每个绑定拥有稳定的独立槽位；引用和切片保存运行期借用凭证，复制视图不提前释放原借用。临时凭证在完整表达式结束释放，绑定凭证在所属块结束释放。重借用遵守同根投影保守重叠规则。

环境按声明逆序清理。解释器分配统一进入 memory.c；退出首先清理活动环境和宿主输出，再回收剩余受控内存。不通过进程退出替代已提交资源的显式清理。
